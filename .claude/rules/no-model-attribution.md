# no-model-attribution

Never add attribution, credit, a signature, or a disclosure that identifies an agent, assistant, model, model provider, or agent runtime as the creator or contributor to work.

This prohibition applies to every current and future runtime, agent, and subagent. It applies to conversation output and every authored artifact, including source code comments, documentation, generated files, commit messages, co-author trailers, pull request titles and bodies, issues, release notes, footers, banners, metadata, and links to agent or chat sessions.

Do not add phrases such as `Generated with Claude Code`, `Generated by AI`, model completion credits, assistant attribution, model-branded signatures, robot symbols used as authorship marks, or links that expose the originating agent session.

## delegation

Pass this rule explicitly to every delegated agent. Subagents return work without self-attribution and must pass the same instruction to agents they delegate to.

## permitted-technical-references

Model, provider, and runtime names are permitted only when technically necessary, such as configuration keys, compatibility documentation, debugging evidence, migration instructions, or user-requested comparisons. A technical reference must not present the model or agent as an author, contributor, or source of credit.

## preserved-notices

Do not remove legally required third-party licenses, copyright notices, provenance records, or upstream attribution. This rule prohibits agent self-attribution, not attribution required for work created by people or third parties.
